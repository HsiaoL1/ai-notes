## 笔记约定

- 一篇一个主题，放在 `notes/`，用 kebab-case 命名
- 每篇开头写清**适用对象**和**记录时间**，工具迭代快，过期信息要能一眼认出
- 资源必须带链接和一句话说明：**它解决什么问题**，而不是"很好用"
- 结论优先：先给可执行的步骤，再给理由

## 为什么写这个

AI 工具半年一换，但**方法**的保质期长得多。这里记的主要是那些换工具也不会过期的部分：怎么描述需求、怎么给证据、什么时候该怀疑它。
